念念小屋官网 2.0

1. 解压整个文件夹。
2. 双击 index.html 即可在浏览器本地预览，不需要 VPN。
3. 网站包含独立页面、开屏动画、滚动动画、App 截图轮播和手机端适配。
4. 确认满意后，将本文件夹内的所有文件上传到 GitHub 仓库 niannian-cottage-website 的根目录，覆盖旧 index.html，保留其他新文件。
5. GitHub Pages 继续使用 main / (root)。
6. 请在 App 正式发布后更新下载链接，并核对隐私政策与最新 App 功能是否一致。
7. 开屏动画每个浏览器标签页会话只播放一次，避免反复打扰；可点击跳过。
8. 在线 Google 字体加载失败时，会自动使用系统中文字体，不影响网站使用。
